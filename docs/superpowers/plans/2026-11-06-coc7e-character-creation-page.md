# CoC 7e 整卡式车卡页实施计划

设计：`docs/superpowers/specs/2026-11-06-coc7e-character-creation-page-design.md`（已确认）

## 完成标准

- PL 从 `/pl/characters/new` 直接创建完整 sheet v2 人物，不再经过空卡弹窗。
- 邀请链接的新建分支复用同一编辑器并直接提交审核。
- 所有 sheet v2 字段可编辑，派生值、点数账本、年龄和信用提示实时更新。
- 自定义职业/技能/专攻和创作背景不受点数预算强制限制。
- 草稿恢复、清空、离开确认、提交失败保留输入均可用。
- shared、客户端组件和服务端真实路由测试覆盖变更；全量检查、生产构建和浏览器视觉验收通过。

## 阶段 1：共享建卡规则 ✅

步骤：

1. 在 `packages/shared/tests/` 新增建卡账本与年龄提示失败测试，覆盖职业公式、INT×2、基础值差分、动态 DEX/EDU 基础值、信用评级归属、降低不退款、自定义技能和专攻。
2. 新增 `rules/coc7e/creation.ts` 纯函数与类型，经 CoC 命名空间导出。
3. 运行 shared 测试和类型检查。

验证：正常、边界与异常输入均有测试；不改写最终技能值为点数的既有事实源。

## 阶段 2：CoC 规则专属整卡编辑器 ✅

步骤：

1. 先写客户端组件测试，覆盖属性/技能输入、暂空与非法值、职业公式选择、时代切换保留内容、派生值、稀疏技能存储、筛选不丢值、专攻/自定义技能、背景提示和资产建议显式采用。
2. 扩展客户端 `RuleComponent` 的规则建卡编辑器契约；通用页面不直接 import CoC。
3. 在 `apps/client/src/rules/coc7e/` 实现整卡编辑器及按职责拆分的字段组件，复用现有 UI 基础组件。
4. 覆盖武器、护甲、装备、资产、法术、神话典籍与遭遇记录的全部 schema 字段。
5. 添加所有文案到集中 i18n，不新增代码注释或平行样式体系。

验证：组件测试先失败后通过；客户端类型检查通过。

## 阶段 3：页面、草稿与提交 ✅

步骤：

1. 先写草稿存储与页面提交测试：独立 POST、邀请 new submission、完整 payload、失败保留、重复提交、成功清草稿、损坏草稿和上下文隔离。
2. 实现通用建卡页面与版本化 localStorage 草稿，处理存储不可用。
3. 新增 `/pl/characters/new`，独立模式显式选规则，邀请模式锁定规则并加载邀请信息。
4. 人物库两个新建入口导航到新页，删除局部空卡 `CharacterEditor`。
5. `/submit/$token` 的新建分支进入新页，已有人物分支保持不变。
6. 实现有改动离开确认、清空重填确认和提交期间防重。

验证：页面和草稿测试通过；路由与生产路由树生成成功。

## 阶段 4：服务端真实入口集成验证 ✅

步骤：

1. 复用 `apps/server/tests/contract/pl-character-flows.test.ts` 与 `invite-review-flow.test.ts` 的隔离应用入口。
2. 添加完整 sheet v2 创建与邀请提交断言，读取持久化详情验证字段和版本。
3. 添加非法完整卡 400、失败不产生人物或审核等失败路径。
4. 运行相关 contract 测试和 server 全量测试。

验证：通过真实 HTTP 路由和数据库协作验证，不用客户端 mock 代替。

## 阶段 5：视觉与端到端验收 ✅

步骤：

1. 在隔离数据库和端口启动应用，建立专用测试账号，不使用现有开发数据库或生产凭据。
2. 浏览器完成独立建卡、刷新恢复、邀请新建提交和失败重试路径。
3. 对最终页面运行 design-taste app lint 和 inspector，检查 1440、768、390 截图；按 app critique 修正最多三轮。
4. 运行 Biome 限定本次 TS/TSX 改动；若仍无配置则报告，不迁移工具链。
5. 运行 `bun run typecheck`、相关测试、`bun run test`、`bun run check:boundaries`、`bun run build:client`。

验证：所有失败修复后再交付；明确任何未实际执行的外部或未验证链路。

## 修改边界

- 不提交或推送 Git。
- 保留用户对入口和登录页的已有修改。
- 不顺手重构无关 GM 页面，不改变旧卡、历史版本或团内快照。
- 不新增代码注释，不引入依赖，不新增全局视觉 token，除非现有语义 token 确实无法表达且属于本页必要能力。
