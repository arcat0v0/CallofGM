# GM 导演工作台 · HTML 设计提案

在浏览器中直接打开本目录的 `index.html`。无需安装依赖、启动应用、登录或联网；保留仓库目录结构即可加载相对路径图片。以 1440–1920px 桌面为主要设计尺寸，另提供平板和手机断点。

## 设计意图

把主持人的主要操作组织成「设定节奏 → 观察舞台 → 呈现下一句」的连续路径。保留 `docs/DESIGN.md` 的三栏、深色主题、单列阶段列表和聊天气泡要求，重新分配三栏职责。

- 左：叙事节奏、全局音频、角色状态。大面积萌黄色块强化当前阶段；列表选中态沿用 secondary-container。音乐面板提前到角色列表上方，方便连续控场。
- 中：有边界的舞台预览、场景带、待呈现队列。舞台与队列上下相接，减少主持人操作后的视线移动。立绘采用拱形人物框，避免现有不透明素材的矩形背景直接遮蔽舞台。
- 右：聊天、独立秘密筛选、主持人作曲器。暗骰卡同时通过文字、图标与颜色表达私密范围。
- 情报、鉴定和私有笔记以按需展开的面板呈现；成员与团设置收纳于页头。私有笔记是本次 UX 提案，不代表已实现的产品能力。

设计参数：变化程度 7/10、动效 5/10、信息密度 7/10。阶段控制是主要视觉焦点，舞台保持叙事氛围。控件使用 standard scheme；场景转场、立绘与舞台对话使用 expressive scheme。

## 可体验的交互

阶段选中态与说明切换；三处场景切换；两名角色立绘显隐；舞台专注模式；队列逐条呈现、上下移动、静默丢弃与重置；频道筛选；GM 旁白与 NPC 发言；音乐时间轴、播放暂停、前后 30 秒、音量及静音；情报、鉴定、成员和笔记面板。

## Expressive 交互细节

- 播放时间轴：已播放部分为连续波浪，未播放部分为直线，竖向手柄两侧留出间隙，末端保留停止标记。播放时每秒移动一个波长；暂停或拖动时压平。保留原生 range 的方向键、Home / End 操作及可读时间值。
- 音量与播放进度分开：音量采用粗直轨道、竖向手柄及末端标记；不会用波浪暗示音量也在自动推进。
- 播放控制组：连接式非对称内圆角，主按钮有更大面积，播放与暂停状态之间进行形状和图标过渡，按压时收紧圆角。
- 选择与排序：阶段、聊天筛选使用滑动容器指示选中项；队列重排与移除后的位置变化保留连续过渡。
- 舞台：图片解码完成后才转场，加载失败保留原场景。快速连续选择只接受最后一次请求；旧立绘退出动画也不能覆盖较新的显隐选择。
- 弹窗与舞台呈现：位置、缩放采用 spatial 曲线；透明度单独使用 effects 曲线，避免透明度跟随回弹。弹窗进入、按钮关闭与 Escape 退出均有过渡。
- 减少动态效果：静止波浪保留进度含义，停止波形移动，禁用空间过渡并取消正在执行的动画。页面进入后台时暂停演示计时和波形。

所有状态只在本页内存中。阶段切换只演示视觉状态，不实现或模拟服务端权限裁决；音乐时间轴由本地演示时钟推进，音频不实际播放；鉴定不生成骰点；情报不实际发送。队列中 PC 演绎消息更新舞台与聊天，OB 场外消息仅更新聊天。暗骰为预设示例，不代表安全隔离实现。

## 视觉来源与工程边界

- 产品、规则与交互依据：`docs/product.md`、`docs/architecture.md`、`docs/tech-stack.md`、`docs/DESIGN.md`。
- `tokens.css` 为 `apps/client/src/styles/theme.css` 的 `@theme` 内容提取为 `:root` 后的预览快照，未手调角色色。本次在原主题文件补齐规范已有的 12 个动效时长 token，以及 full 圆角和媒体波形周期、匀速 token；原型不另定义一套动效参数。
- 当前为独立 HTML 提案，使用原生语义元素和 CSS 变量表达组件；未引入新的 UI 依赖。正式集成仍使用项目的 React、shadcn/Radix 与 Tailwind utility，并将原型里的布局及动效规格收敛到现有 token 体系。
- 图标来自仓库已安装的 Lucide，内联输出；图片来自 `apps/client/public/demo/`。字体使用本机 Noto 与系统回退，无远程加载。
- [Google Expressive UX 研究](https://design.google/library/expressive-material-design-google-research)：采用颜色、尺寸与容器突出关键动作，同时保留明确文字标签和熟悉的操作模式。
- [Google LinearWavyProgressIndicator API](https://developer.android.com/reference/kotlin/androidx/compose/material3/LinearWavyProgressIndicator.composable)：参考波长、振幅、运动速度、轨道间隙和停止标记。此稿把原生 range 的交互叠加到 SVG 波形上，是 Web 原型实现，不声称使用官方 Expressive Web 组件。暂停压平及控件布局参考本轮用户提供的播放器图与原型自身的交互设计。
- 已尝试查阅 [M3 Button groups](https://m3.material.io/components/button-groups/overview) 和 [官方 Figma 套件](https://www.figma.com/community/file/1035203688168086460)。前者文本入口要求 JavaScript，后者当前工具无法访问；不声明已做官方套件逐像素比对。

## 验证

已运行 Biome 默认规则的 HTML、CSS、JavaScript 检查与格式化（仓库未提供 Biome 配置），检查通过；三个脚本的 Bun 浏览器目标打包通过；本地资源引用、40 个 HTML ID 唯一性、静态选择器与 CSS/motion token 引用检查通过。应用侧仅新增主题 token，没有改动业务代码或依赖。

按项目约定未启动浏览器。视觉呈现、键盘操作、弹窗焦点、缩放和各尺寸溢出待用户验证。建议先试「播放/暂停 → 拖动进度 → 连续切换阶段和场景 → 队列重排 → 弹窗 Escape 退出」，再检查减少动态效果，以及 1440px、768px 和 390px 下的布局。本稿不包含生产接入或端到端验证。
